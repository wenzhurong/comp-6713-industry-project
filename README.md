# COMP6713 Industry Project

## Project Introduction 

This project is an industry project for the UNSW COMP6713 course. It aims to analyze employment data related to the technology industry and explore the relationship between factors such as salary levels, job qualifications, and work arrangements. The project uses Jupyter Notebook for data analysis and visualization to help understand the key factors affecting employment trends in the technology industry.

## Project Structure

```
comp-6713-industry-project/
├── raw_data/ 				  # Raw data folder
├── salary.ipynb 			  # Salary analysis and train notebook
├── seniority.ipynb 		  # Seniority analysis and train notebook
├── work_arrangement.ipynb 	  # Work arrangement analysis and train notebook
├── README.md 				  # Project description file
└── LICENSE 				  # Project license (GPL-3.0)
```

## How to use

1. Clone repository

    ```
    git clone https://github.com/wenzhurong/comp-6713-industry-project.git
    ```

2. Run all Jupyter Notebook files
